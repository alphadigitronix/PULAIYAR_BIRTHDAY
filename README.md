🚀 How to Run
Step 1: Install Python

Download and install Python 3 from the official Python website.

Make sure Python is added to your system PATH during installation.

Step 2: Save the Code

Save the Python program as:

pulaiyar.py
Step 3: Run the Program

Open Command Prompt / Terminal in the project folder and run:

python pulaiyar.py

You can also open the .py file using IDLE, VS Code, or another Python IDE and press Run.
